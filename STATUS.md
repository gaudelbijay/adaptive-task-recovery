# Project Status

Living tracker for the repository. Stable research design lives in [`docs/`](docs/);
frequently updated execution notes live in [`ai-notes/`](ai-notes/).

## Current status

**Phase:** Pre-Phase 0 — research reframing complete; simulator formally selected.

The project now studies whether a robot can tell when something it was asked
to do has become impossible — because the world changed in a way that can't
be undone — and still do whatever remains achievable, without faking success
by doing something it was never asked to do. Target embodiment is a simulated
humanoid; full breakdown in [`docs/00-project-overview.md`](docs/00-project-overview.md).
The previous failure-monitor/physical-recovery question has
been superseded, but humanoid manipulation and whole-body control remain part of
the execution platform. Investigation code exists (`spikes/maniskill_humanoid_spike/`,
not project architecture — see D-006): ManiSkill3 humanoid loading, deterministic
scripted events, object-level interventions, RGB-D observations, and basic
reach/grasp manipulation are all confirmed working (D-009, D-010, D-011).
Known platform gap: `mplib`-based motion planning doesn't build on Apple
Silicon macOS (worked around via `pinocchio`). A task schema + intervention
set draft also exists (`spikes/task_schema_draft/`, D-013) — proposed, sent
for teammate review 2026-08-02 (`ai-notes/review-request-task-schema.md`),
not yet accepted. **ManiSkill3 formally selected as the primary simulator
2026-08-02 (D-033)** — I-003 closed without an Isaac Lab spike; D-006 only
required a spike step, and seven weeks of ManiSkill3-specific evidence
(D-009 through D-032) already cleared that bar. Still open: pretrained
model selection (I-004) and compute planning.

**Team model:** two contributors. Phase 0 and benchmark construction are shared.
Person A then leads representation/language/feasibility; Person B leads
policy/humanoid execution. Interfaces, integration, and evaluation remain shared.
