# Project Status

Living tracker for the repository. Stable research design lives in [`docs/`](docs/);
frequently updated execution notes live in [`ai-notes/`](ai-notes/).

## Current status

**Phase:** Phase 0 — simulator selected, core schema accepted and promoted to `src/atr/`.

The project now studies whether a robot can tell when something it was asked
to do has become impossible — because the world changed in a way that can't
be undone — and still do whatever remains achievable, without faking success
by doing something it was never asked to do. Target embodiment is a simulated
humanoid; full breakdown in [`docs/00-project-overview.md`](docs/00-project-overview.md).
The previous failure-monitor/physical-recovery question has
been superseded, but humanoid manipulation and whole-body control remain part of
the execution platform. Investigation code exists (`spikes/maniskill_humanoid_spike/`,
not project architecture — see D-006): ManiSkill3 humanoid loading, deterministic
scripted events, object-level interventions, RGB-D observations, and basic
reach/grasp manipulation are all confirmed working (D-009, D-010, D-011).
Known platform gap: `mplib`-based motion planning doesn't build on Apple
Silicon macOS (worked around via `pinocchio`). The task schema (D-013) —
`Goal`/`Constraint`/`GoalGraph`, oracle feasibility, the intent guard — is
**accepted and promoted to `src/atr/` as of 2026-08-02 (D-037)**, resolving
`ai-notes/review-request-task-schema.md`'s four open questions (one led to
a real fix: `Goal.depends_on` was dead schema surface, now wired via
`goal_dependencies_satisfied()`). **Read the review document's status
banner before treating this as settled** — it was self-resolved by the
project owner, not independently reviewed by the teammate it was written
for; genuinely different from a second person's independent judgment.
Everything else (language parsing, vision, the learned policy, the
end-to-end pipeline) remains spike-stage evidence in
`spikes/task_schema_draft/`, not yet promoted. **ManiSkill3 formally
selected as the primary simulator 2026-08-02 (D-033)** — I-003 closed
without an Isaac Lab spike; D-006 only required a spike step, and seven
weeks of ManiSkill3-specific evidence (D-009 through D-032) already
cleared that bar. **Pretrained model selection resolved 2026-08-06
(D-062, closing I-004):** language backbone = `instruction_parser.py`
(already the only real candidate); SSL visual baseline = DINOv2, with
CLIP retained as the pipeline's real zero-shot feasibility backend and
H1's required language-supervised comparison point, not discarded.
Further compute planning still open. **CLIP/
DINOv2 made CUDA-aware with CPU fallback 2026-08-02 (D-036)** — runs on a
GPU automatically when one's available, no code changes needed; ManiSkill
sim backend deliberately left CPU-only (object add/remove is unsupported
under GPU-batched sim, unconditionally — a correctness requirement, not a
performance fallback).

**Team model:** Phase 0 and benchmark construction are shared foundations.
Representation/language/feasibility and policy/humanoid execution are the
two work areas on top of that. Interfaces, integration, and evaluation
remain shared.
