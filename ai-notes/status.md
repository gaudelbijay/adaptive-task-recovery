# Project Status

Last updated: 2026-07-24

## Current phase

Pre-Phase 0: planning and repository organization.

## Summary

The project scope and design are documented, but implementation has not started.
The project is simulation-only and will use ManiSkill for training and
evaluation. The current repository work is organizing stable documentation under
`docs/` and adding lightweight project trackers under `ai-notes/`.

## Immediate focus

Prepare the Phase 0 repository scaffold, validate the local ManiSkill
installation, and run a basic simulator example before implementing a custom
humanoid environment.
