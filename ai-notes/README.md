# AI Project Notes

This directory holds two things that don't belong in [`../docs`](../docs/) (stable
design) or [`../STATUS.md`](../STATUS.md) (fast-glance current status/todo/changelog):

- [decisions.md](decisions.md) — architecture decision log: what was decided, why, and the consequences
- [issues_and_risks.md](issues_and_risks.md) — active blockers, open questions, and risks with mitigations

## Maintenance rules

- Record decisions that would be expensive or confusing to revisit.
- Close resolved risks instead of deleting their history.
- Use dates in `YYYY-MM-DD` format.
